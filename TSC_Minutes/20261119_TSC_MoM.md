## 2. Documentation as Code

**Presentation by Eloi (Savoir-faire Linux) and demo by Camille (Schneider Electric).**

Item 2.5 from the roadmap

Proposal to migrate SEAPATH documentation from Confluence to Markdown, using Read the Docs.

**Main motivations:**
- Move away from a proprietary documentation platform.
- Improve documentation versioning and alignment with SEAPATH releases.
- Adopt a documentation approach widely used by open-source projects.
- Benefit from free Read the Docs hosting for open-source projects.
- Simplify maintenance and contributions from the community.

**Demo:**
- Existing Confluence documentation migrated to Markdown.
- Automatic documentation generation.
- Integration of documentation from multiple repositories, including Service VM Manager and Ansible Galaxy Collection.
- Possibility to manage documentation for different SEAPATH versions through Git branches.

**Decision and next steps:**
- A formal TSC vote on the migration will take place during the **December 10 TSC meeting**.
- If approved, Confluence will be switched to Read The Docs.
- The community is invited to review the proposal, provide feedback and raise questions before the vote.

**Future opportunities:**

The Markdown documentation could be used as a knowledge base for AI-powered assistance, using RAG (Retrieval-Augmented Generation), for example through a chatbot providing guidance and troubleshooting support to SEAPATH users.

## 3. Sovereign Tech Fund (STF)

The **Sovereign Tech Fund (STF)** is a German publicly funded initiative supporting critical open-source software infrastructure.

Its objective is to strengthen digital sovereignty by providing funding to open-source projects, particularly for maintenance, security and long-term sustainability.

- Savoir-faire Linux and BearingPoint are pursuing funding through this initiative for SEAPATH and CoMPAS, primarily for maintenance and cybersecurity activities.
- The TSC voted on October 30 to endorse the initiative.
